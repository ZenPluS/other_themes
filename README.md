# Other themes

Nine additional OrbitKanban themes. Official app themes and themes from [orbit_themes](https://github.com/ZenPluS/orbit_themes) are excluded. Original names and palette colors are preserved.

## Use in OrbitKanban

Requires OrbitKanban 3.8.0 or newer.

1. Open **Settings → Appearance repositories**.
2. Choose **Themes** and enter `ZenPluS/other_themes`.
3. Click **Add repository**, then **Save settings**.
4. Choose a palette in **Themes & atmosphere**.

Downloaded palettes work offline. Refresh explicitly for updates; edited palettes are preserved.

## Manifest

`orbit-themes.json` uses the declarative `orbitkanban-themes` format, version 1, with pack ID `other`. Each theme has a stable kebab-case ID, name, and six-digit hexadecimal `background`, `surface`, `text`, and `accent` colors. No scripts or external assets are included.
